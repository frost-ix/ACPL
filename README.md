# ACPL (AI CLI PowerShell Launcher)

[En](docs/README.md)

ACPL은 Windows 환경에서 Claude Code, Antigravity, Codex 등 다양한 AI CLI 도구를 폴더별로 관리하고 동시에 멀티 세션으로 실행할 수 있도록 돕는 PowerShell 기반 실행기입니다.

여러 프로젝트 디렉토리를 오가며 터미널 창을 개별적으로 띄우고 명령어를 반복 입력하는 번거로움을 줄이고, 단일 인터페이스에서 폴더별 세션 전환과 대화 기록 저장을 손쉽게 처리할 수 있도록 개발되었습니다.

---

## 주요 기능

- **디렉토리별 세션 관리**: 프로젝트 폴더 경로와 별칭(Alias)을 등록해두고 클릭 한 번으로 해당 위치에서 지정한 AI CLI 세션을 즉시 시작할 수 있습니다.
- **반응형 탭 시스템**: 여러 세션을 동시에 띄워둘 때 탭이 늘어나도 활성화된 탭 위주로 표시되며, 비활성화된 탭은 축소 상태에서도 이니셜이 식별 가능하도록 탭 영역을 자동 조절합니다.
- **사용량(Quota) 자동 갱신**: Claude CLI 세션 연결이 완료되면 현재 플랜 한도(5시간 한도 / 주간 한도 퍼센트)를 자동으로 체크하여 상단 탭 뱃지에 실시간으로 표시합니다.
- **원문 대화 추출 (.md)**: AI 토큰 소비 없이 현재 터미널 버퍼에 출력된 전체 대화 내용을 원문 그대로 마크다운(.md) 파일로 즉시 저장할 수 있습니다.
- **PDF 보고서 생성**: 진행된 대화 내용을 핵심 위주로 요약 정리하여 지정한 폴더에 PDF 문서로 생성합니다.
- **설정 자동 동기화 및 마이그레이션**: 설정 정보(`directory.json`)는 `%APPDATA%\ACPL` 경로에 안전하게 보관되며, 실행 파일 동일 경로 백업 및 이전 설정의 자동 이전을 지원합니다.
- **세션 안전 종료 보호**: 세션이 활성화된 상태에서 프로그램을 닫을 때 오작동이나 예기치 않은 종료를 방지하기 위해 경고 대화상자를 띄웁니다.

## 사전 요구 사항

- Windows 10 이상
- Node.js (v18 이상 권장)
- 사용하는 AI CLI 도구 (Anthropic Claude Code 등) 전역 설치 및 환경변수 설정

---

## 실행 및 빌드 방법

### 개발 환경 실행

```bash
# 패키지 설치
npm install

# 프로그램 실행
npm start
```

### 실행 파일 (.exe) 빌드

```bash
# 포터블 및 실행 디렉토리 빌드
npm run build:exe
```

빌드가 완료되면 `dist/` 디렉토리 내에 패키징된 실행 파일이 생성됩니다.
